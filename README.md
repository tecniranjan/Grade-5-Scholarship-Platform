# GENIUS ONE - Blood Report Platform

> Know Your Child's Exact Strength — Like a Blood Report

## Features

- **14 Nipunatha (Competency) Analysis**: Detailed breakdown per skill area
- **Scatter Question Ordering**: Questions randomized for students, mapped to Nipunathas in backend
- **Monthly Advancement**: Curriculum tagged by month progression
- **Trilingual Support**: Sinhala, Tamil, English throughout
- **Grade Slots**: Exam schedules for Grades 3, 4, 5
- **Blood Report**: Visual per-Nipunatha performance analysis with trends
- **PDF Export**: Downloadable Blood Report

## Quick Start

```bash
docker-compose up --build
```

- Frontend: http://localhost:3000
- Backend API: http://localhost:3001
- Database: localhost:5432

## Tech Stack

- **Frontend**: React + Vite + Tailwind CSS
- **Backend**: Node.js + Express
- **Database**: PostgreSQL 15
- **Container**: Docker Compose
